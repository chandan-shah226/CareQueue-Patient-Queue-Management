# CareQueue – Smart Patient Queue Management System

Welcome to the **CareQueue** repository! 

CareQueue is a digital queue management application designed to increase operational efficiency in clinics and drastically improve the overall patient experience by reducing physical crowding in waiting rooms.

## Overview
The product leverages a centralized web-based architecture, allowing patients to generate virtual tokens remotely via a Web Application, and provides an interface for doctors to manage patient flow. It dynamically provides insights to patients regarding their estimated wait times and the live status of the queue.

## Project Structure
- **`backend/`**: Contains the Python Flask application, SQLAlchemy models, and API routing.
- **`templates/` & `static/`**: Vanilla HTML, CSS, and JS files powering the dynamic frontend.
- **`demo/`**: Contains the automated cinematic showcase created for LinkedIn and product demonstration.
- **`carequeue.db`**: SQLite database (generated automatically upon running the application).
